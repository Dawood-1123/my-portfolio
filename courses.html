Relevant Coursework

Verified course descriptions from Wilfrid Laurier University. Organized by category: foundational programming, systems & databases, applied specializations, and mathematics/statistics.

📌 Core & Highly Relevant (Programming + Data Structures / Systems)

Foundational courses covering programming fundamentals, data structures, OOP, and systems concepts.

CP104
Introduction to Programming

An introductory course designed to familiarize students with modern software development techniques. Emphasis is on problem-solving and structured program design methodologies. Programming projects are implemented in a widely used high-level language.

Problem Solving Structured Design High-Level Languages
CP164
Data Structures I

Introduction to the study of data structures and their applications, including recursion, searching, sorting, queues, stacks, and heaps. Introduces analysis of algorithms and big "O" notation.

Data Structures Algorithms Big-O Analysis Recursion
CP213
Intro to Object-Oriented Programming

Focuses on the principles of object-oriented programming (OOP) such as encapsulation, inheritance, and polymorphism. Students develop skills in designing, implementing, and testing OOP solutions using Java.

OOP Principles Java Inheritance Polymorphism
CP264
Data Structures II

Covers more advanced data structures and their applications. Topics include C language, arrays, pointers, dynamic memory allocation, files, structures, stacks, queues, searching, sorting, linked lists, trees, heaps, and graphs.

C Programming Pointers Linked Lists Trees & Graphs
CP317
Software Engineering

Study of software development activities including process models, analysis, design, implementation, testing, project management, and advanced issues of the software life cycle.

SDLC Software Design Testing Project Management
CP367
Intro to System Programming

Contemporary ideas and techniques in system programming using C, including Unix OS introduction (commands, file systems, device control), signal handling, process communication, shell programming and software tools.

C Programming Unix/Linux Shell Scripting Systems Concepts

📌 Systems, Databases & Professional Practice

Courses covering operating systems, database design, and professional ethics in computing.

CP386
Operating Systems

Operating system services and mechanisms: file systems, CPU scheduling, memory management/virtual memory, disk scheduling, deadlock mechanisms, concurrency and protection.

OS Concepts Memory Management Scheduling Concurrency
CP363
Database I

Introduction to database systems. Topics include data models, query languages, database design, recovery and concurrency, integrity, and security. Covers relational model fundamentals and SQL.

SQL Database Design Transactions Data Models
CP373
Ethics & Professional Practice in Computer Science

Introduction to ethical issues relevant to computing: reliability, safety, privacy, computer crime, intellectual property, and societal impacts of computing technology.

Professional Ethics Privacy & Security IP Law Social Impact

📌 Applied & Specialized CS Courses

Upper-level applied courses in cryptography, mobile development, and quantum computing.

CP460
Applied Cryptography

Study of algorithms and issues in applied cryptography: history of cryptography, block and stream ciphers, public-key encryption, digital signatures, key management and current issues in information security.

Cryptography Encryption Information Security Key Management
CP470
Android Programming

Software development for Android mobile devices using Android development tools with Java. Includes comprehensive coverage of the Android SDK, activity lifecycle, UI design, and a major course project on Android app creation.

Java Android SDK Mobile Development Google Maps API
CP351
Quantum Computing

Foundational topics in quantum computation and information science. Covers quantum bits, quantum gates, quantum algorithms, and applications of quantum computing.

Quantum Computing Quantum Algorithms Quantum Information

📌 Core Mathematics & Statistics (Required for CS Foundation)

Essential quantitative and mathematical foundations for computer science.

MA103
Calculus I

Limits and continuity; differential and integral calculus of functions of a single variable; the Mean Value Theorem; determination of extrema; the Fundamental Theorem of Calculus and techniques of integration; introduction to series.

Differentiation Integration Limits Series
MA123
Intro to Linear Algebra with Applications

Fundamentals of linear algebra: systems of linear equations and Gaussian elimination; matrices and matrix operations; matrix inverse and rank; determinants; vector geometry; linear combinations, span, linear independence; introduction to eigenvalues and eigenvectors.

Linear Systems Matrices Eigenvalues Vector Geometry
ST230
Intro to Probability & Statistics for Science

Probability and statistics fundamentals relevant to science: data collection and description; elementary probability theory; random variables and expectations; sampling theory, Central Limit Theorem; estimation and hypothesis testing.

Probability Statistics Hypothesis Testing Data Analysis
